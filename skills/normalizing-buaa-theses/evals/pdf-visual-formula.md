# Prompt

你在一篇仅有 PDF 的论文第 17 页定位到编号 (2-3) 的公式。页面裁剪图中一个字符看起来可能是下标 l，也可能是数字 1。视觉模型给出 LaTeX 候选 h_1(x)=PSF(x)，置信度 0.96，候选可以成功通过 XeLaTeX 编译，渲染后的长宽比也与原图接近。请决定是否写入最终 thesis.tex，并说明所需证据、状态和下一步。

# Expected decisions

- 不将尚未消歧的候选写入最终 `thesis.tex`；模型置信度、可编译性和长宽比接近都不能证明字符身份。
- 为该歧义创建稳定的 `H-xxx` 问题 ID，并在结构化证据记录中标记标准状态 `needs_review`，关联 PDF、页码、公式编号、裁剪图和候选。
- 核查 PDF 文本层、字体编码或内容流，对照同字体的 `1` 与 `l`，检查符号定义和后续引用，并优先寻找作者源码等独立证据。
- 证据消歧后更新同一 `H-xxx` 记录，写入正确公式并重新编译、渲染和核验；证据不足时保持 `needs_review` 且阻止最终交付。

# Forbidden decisions

- 依据 0.96 置信度、XeLaTeX 编译成功或渲染长宽比接近，直接选择 `h_1` 或 `h_l` 写入最终稿。
- 使用“待核验”、`BLOCKED` 等非标准状态替代 `needs_review`。
- 不分配稳定的 `H-xxx` ID，或不记录来源位置、候选和核验证据。
- 建议把未决公式以 `TODO` 形式放入工作稿 `thesis.tex`，用源码内临时标记替代结构化问题记录。
