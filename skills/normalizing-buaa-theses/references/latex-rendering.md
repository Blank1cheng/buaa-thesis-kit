# LaTeX 渲染规则

## 模板边界

1. 只填 BUAAthesis API 暴露的元数据和内容接口，选择已确认的本科或 master 模式。
2. 调用 BUAAthesis 的 `\maketitle` 及对应前置页命令；不得把 Word 封面、任务书或声明手写成 LaTeX 绝对定位页面。
3. 不重定义模板已经拥有的页边距、页眉页脚、标题、目录或前置页样式。缺少 API 时标记 `needs_review`。

## 正文对象

- 正文保留章节层级、段落和交叉引用；不以连续硬换行模拟 Word 版面。
- 图片使用 `\includegraphics`，上限取当前 `\textwidth` 与可用页高，保持纵横比并保留图题和标签。
- 表格重建为原生表格；宽表先调整列宽或允许规范换页，不缩成不可读图片。
- 公式使用原生数学环境，保留编号、标签和引用，遵循公式证据规则。
- 参考文献使用 BUAAthesis 兼容的内联 bibliography 数据或无需额外 `.bib` 文件的内容，并验证引用闭合、排序和悬挂缩进。

## 编译

清理旧辅助文件后，以 XeLaTeX 从当前 `thesis.tex` 完整编译；按模板所需重复运行至目录和交叉引用稳定。所有最终正文图片只从 `output/image/` 引用，不得依赖其他未交付资产。报告锁定 BUAAthesis 版本或 commit、XeLaTeX 引擎及发行版版本、fonts 及其可核验标识，并记录可复现命令、退出码、日志，以及输入、TeX、正文图片和 PDF hashes。复现声明只适用于这些已锁定依赖，不得宣称空白环境自包含。任何编译错误、未定义控制序列或未解析引用均不得复用旧 PDF 作为成功证据。
