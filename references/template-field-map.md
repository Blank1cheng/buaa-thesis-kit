# 模板字段映射

字段映射必须服务于 Word 模板填充；Word 为权威源，PDF 从 Word 导出。每个自动提取字段都应在报告中保留元数据、置信度、证据三类信息，证据可为段落文本、页码、表格单元格或文件属性。

## 封面与任务书

| 目标字段 | 常见来源 | 处理规则 |
| --- | --- | --- |
| 论文题目 | 封面标题、摘要标题、文件名 | 多处一致可高置信度；不一致时使用封面并人工复核 |
| 学生姓名、学号 | 封面信息栏、任务书表格 | 表格标签优先；缺失时不得从作者属性直接覆盖 |
| 学院、专业、班级 | 封面或任务书 | 保留原文全称，简称只作为低置信度候选 |
| 指导教师 | 封面、任务书、摘要页 | 多导师按原顺序保留，职称不确定时单独写入备注 |
| 日期 | 封面落款、任务书日期 | 统一成模板格式；来源冲突时标记人工复核 |

## 摘要与目录

- 中文摘要从“摘要”“关键词”之间抽取；关键词用原分隔符解析后按模板重排。
- 英文摘要从“Abstract”“Key Words/Keywords”之间抽取；不要机器翻译缺失内容。
- 目录优先由 Word 标题样式生成；源目录只用于校验章节顺序。
- 正文标题层级按规则文件识别，一章、1、1.1、1.1.1 不应混用为同级。

## 正文对象

- 图片复制到 `output/image`，Word 内使用嵌入图；TeX 内使用相对路径。
- 表格应保留为 Word 表格，不要截图化；超宽表可横向页或缩放，但需报告说明。
- 公式优先保留为 Word 公式对象或可编辑公式；无法编辑时可作为图片保留，并记录公式/equation handling 警告。
- 参考文献保持编号、作者、题名、来源、年份等原始信息，不确定字段不得补造。
