# Agent-first 北航整篇论文规范化 Skill 设计

## 目标

交付一个可被通用 Agent 加载的整篇论文规范化 Skill。输入为 DOCX 或 PDF，Agent 根据源文档证据建立论文模型，使用 BUAAthesis 官方 LaTeX 实现生成 PDF，并通过独立 Harness 反复验收。Skill 是主入口，Python 脚本和 OCR 引擎只是可选工具，不能成为执行前提。

当前阶段同时支持本科和硕士模式选择，但本科规则和本科样例是首个完整验收对象。不得用本科规则静默处理硕士论文，也不得在无法确定培养层次时猜测。

## 角色边界

### Skill

Skill 提供 Agent 必须遵守的操作顺序、格式规则、证据格式、失败分类和收口标准。它不把整篇处理压缩为一条本地命令，也不假设某个固定 OCR、操作系统或 Office 安装存在。

### Agent

Agent 是实际执行者，负责：

- 读取 DOCX 原始 OOXML、表格、文本框、关系、OMML、OLE 和媒体；
- 读取 PDF 文本层、坐标和页面图像；
- 查看关键页面和公式裁剪图，完成视觉识别和版面判断；
- 建立带来源证据和置信度的论文模型；
- 填充 BUAAthesis 数据接口，编辑 LaTeX 并修复明确失败；
- 对封面、任务书、摘要、目录、正文、图表、公式和参考文献逐页复核。

Agent 不得仅依据自己的文字报告宣布通过，必须消费 Harness 的结果并提供视觉证据。

### Renderer

Renderer 只把已确认的模型渲染为 TeX/PDF。封面和前置页必须调用 BUAAthesis 自身实现，不允许重新手写相似版式。Renderer 不负责猜测缺失内容或判断语义正确性。

### Harness

Harness 是独立裁判，不是工作流控制器。它负责确定性检查、证据汇总和稳定失败编号，不能通过修改规则掩盖输出问题。Harness 至少提供以下配置：

- `latex_pdf`: 默认 PDF 合规门禁；
- `word_editable`: DOCX 内容保留和可编辑性门禁；
- `agent_visual_review`: 关键页面视觉证据和 Agent 判定门禁；
- `legacy_word_layout`: 旧 Word OOXML 实验的兼容门禁，不阻塞 LaTeX PDF 路径。

### 可选工具

解压 DOCX、抽取 PDF 坐标、XeLaTeX 编译、截图、哈希和现有 validators 都可以由 Agent 调用。外部 OCR 或公式识别器仅在 Agent 无法直接读取图像或需要批量候选时使用，其输出始终是候选证据，不是最终事实。

## 输入与能力检测

每次执行先记录输入路径、SHA256、大小和输入类型，再检测当前 Agent 是否具备：

- DOCX/ZIP/XML 读取能力；
- PDF 文本与坐标读取能力；
- 页面或图片视觉理解能力；
- XeLaTeX 编译能力；
- DOCX 写入或保留能力。

缺少某项能力时，Agent 应选择可用工具或将受影响项目标为 `needs_review`。不得因为缺少 OCR 就把图片页当作空白，也不得因为视觉模型可读图就跳过源 XML。

## 来源优先级

DOCX 输入固定采用以下顺序：

1. `word/document.xml`、header/footer、footnote/endnote 和文本框中的 `w:t`；
2. 表格结构、样式、编号、关系和 section 信息；
3. OMML 和 MathType/OLE 原生公式；
4. 媒体文件及其关系；
5. 渲染页仅用于视觉验证。

PDF 输入固定采用以下顺序：

1. 带页码、坐标、字体和字号的文本层；
2. 页面结构和对象信息；
3. Agent 对页面图像的视觉识别；
4. 外部 OCR 候选。

任一低优先级结果不得覆盖无冲突的高优先级原生数据。

## Agent 工作流

1. **身份绑定**: 记录输入路径、SHA256、大小和培养层次。
2. **结构清点**: 建立封面、书脊、任务书、声明、中英文摘要、目录、正文、致谢、参考文献、附录、图表和公式清单。
3. **证据模型**: 生成 `model.json`，每个关键字段记录值、来源位置、提取方式、置信度和复核状态。
4. **内容规范化**: 修复硬换行、章节层级、题注关联、参考文献条目和任务书段落，不改写论文事实。
5. **资源处理**: 图像动态适配版心；表格保持语义结构；公式按原生结构、文本、视觉识别的顺序处理。
6. **模板填充**: 只填充 BUAAthesis 公开变量和正文数据文件，调用模板自己的封面及前置页实现。
7. **编译与截图**: 使用 XeLaTeX 编译，渲染关键页和所有存在风险的页面。
8. **Harness 验收**: 运行对应配置，读取 `failure_queue.json`。
9. **单失败修复**: 每轮只处理一个最高优先级稳定失败 ID，保留前后证据。
10. **收口**: 无阻断项和复核项时标为 `pass`；有可信输出但仍需确认时为 `needs_review`；缺失关键内容、编译失败或身份不一致时为 `failed`。

## 公式子流程

公式按 `OMML/MTEF > 可验证文本 > Agent 视觉识别 > 外部 OCR` 排序。每个公式必须有稳定 ID、页码或段落位置、源证据图、候选 LaTeX、独立编译结果和最终状态。

Agent 视觉识别公式时必须：

1. 裁剪完整公式，不包含编号和相邻正文；
2. 转写原生 LaTeX，不使用公式截图作为最终正文；
3. 独立编译候选；
4. 对照源图检查上下标、分式、根号、矩阵、括号、希腊字母和编号；
5. 无法排除歧义时保留 `needs_review`，不得猜测。

视觉模型或 OCR 的置信度不能单独使公式通过。原生来源或 Agent 逐项视觉确认，加上编译成功，才允许写回正文。

## 输出契约

公开产物只允许位于一个 `output/` 目录，其中图片证据使用单独子目录：

```text
output/
  thesis.docx
  thesis.pdf
  thesis.tex
  model.json
  report.md
  failure_queue.json
  image/
```

过程裁剪图、独立公式编译文件、临时页面和日志默认放入临时目录并在完成后删除。需要复核的页面或公式证据复制到 `output/image/`，并在报告中使用相对路径引用。

`thesis.pdf` 是格式合规的主交付物。`thesis.tex` 是其可复现源。`thesis.docx` 保存可编辑内容和源结构；若 PDF 输入无法可靠恢复完整可编辑 Word，必须明确标记 `needs_review`，不得用整页截图伪造可编辑文档。

## Harness 门禁

Harness 必须检查：

- 输入和候选产物的路径、SHA256、大小及提交版本；
- `model.json` schema、字段证据和未确认值；
- 模板示例、调试文本、本地绝对路径和占位符污染；
- 章节、摘要、目录、图表、公式、参考文献和页码的一致性；
- XeLaTeX 编译、缺图、缺字体、溢出和异常空白页；
- 纸张尺寸、页边距、页码体系和目录目标；
- 公式是否为原生 LaTeX、是否独立编译、是否保留视觉证据；
- Agent 是否实际检查规定页面，而不是只提交结论；
- `output/` 是否只含公开产物。

每个失败项至少包含 `id`、`gate`、`reason`、`region`、`evidence`、`expected`、`suggested_fix` 和 `can_fix_now`。一个门禁通过不能覆盖其他门禁失败。

## 视觉验收

Agent 至少检查：

- 封面和书脊；
- 任务书全部页面；
- 中英文摘要首页；
- 目录首末页；
- 正文第一页及每章首页；
- 每个包含复杂图、表或公式的页面；
- 参考文献首末页；
- 致谢、附录及异常页。

检查内容包括元素是否缺失、重叠、越界、孤行、字号突变、标题层级错误、图题分离、公式截断、参考文献悬挂缩进及页码错误。视觉判定必须关联截图路径和页码。

## Skill 验收

Skill 采用 Agent 场景测试：

1. 无 Skill 时记录 Agent 在 DOCX、PDF 和公式场景中的基线失败；
2. 加载 Skill 后用相同场景验证来源优先级、证据模型、公式复核和 Harness 收口；
3. 使用真实截断 DOCX 完成一次本科 LaTeX/PDF 闭环；
4. 使用真实 PDF 验证文本层、页面视觉、公式定位和不确定项不会被静默通过；
5. 验证最终 `output/` 符合输出契约，所有结论可追溯。

验收不要求任何一个特定 OCR 引擎存在。Skill 必须在有视觉能力和无视觉能力两种 Agent 场景下给出正确行为。
