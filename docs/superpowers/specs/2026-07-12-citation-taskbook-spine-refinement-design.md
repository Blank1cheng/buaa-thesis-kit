# 北航论文引用、公式说明、任务书与书脊精修设计

日期：2026-07-12

## 1. 目标

在不替换 BHOSC/BUAAthesis 本科模板、不放宽 Harness 的前提下，修复当前 LaTeX 主流程中的四类格式问题：

1. 正文引用由基线上的裸 `[n]` 改为右上角上标，并与参考文献条目形成真实交叉引用。
2. 以“式中、其中、这里、上式中”等提示词开头的公式说明段顶格排版，提示词不得单独成行。
3. 任务书技术要求、工作内容和主要参考资料不再拼接两段横线；内容增加时增加横线行数，不缩小规定字号。
4. 书脊采用用户确认的黄金版窄框单轴结构，题名、姓名、学校沿同一竖直中轴排列。

最终仍由 `model.json` 驱动，DOCX 原始 XML 优先，PDF 输入保留低置信度复核机制。

## 2. 已确认根因

### 2.1 引用不是交叉引用

当前正文段落经 `tex_escape` 后直接写入 LaTeX，`[2]` 等引用只是普通字符。参考文献同样通过自定义段落命令输出，没有稳定的 `\bibitem` 键，因此 LaTeX 无法解析、压缩或校验引用目标。

### 2.2 公式说明沿用正文首行缩进

当前所有普通段落走同一个渲染分支。BUAAthesis 的正文段落默认首行缩进，导致“式中”“这里”等说明词没有从正文左边界开始；源文本中的物理换行还可能把提示词和解释内容分开。

### 2.3 任务书横线由两套机制拼接

当前任务书使用 `\uline{文字}` 后追加 `\leaders\hrule`。两者的线宽和垂直偏移不同，文字末尾出现可见接缝。参考资料还插入逐字符 `\allowbreak`，造成不自然断行。

官方类已经提供 `\ulinel{内容}`，它用同一个 `\uline` 覆盖整行 `\makebox`。因此应把内容预排为视觉行，再让每一行只调用一次 `\ulinel`。

### 2.4 书脊被实现为三列

当前书脊由三个横向 `minipage` 分别承载题名、姓名和学校，因而形成三列分散布局，并且没有黄金参考中的窄框。该实现与用户确认的单轴书脊不同。

## 3. 方案选择

采用“语义化 LaTeX 补丁层”，不直接修改 `buaathesis.cls`，也不对最终 PDF 做覆盖式后处理。

原因：

- 保持官方模板文件可校验、可升级。
- 引用、公式说明、任务书和书脊可以独立测试。
- Harness 能从模型、TeX 和 PDF 三层验证行为，而不只比较截图。
- 修复同时改善语义正确性和视觉正确性。

## 4. 数据与渲染设计

### 4.1 引用键与交叉引用

为每个已提取参考文献生成确定性键：`ref-<编号>`。编号来自条目显式编号；没有可信编号时不得猜测，条目标记为 `needs_review`。

正文仅转换符合以下条件的引用标记：

- 形式为 `[2]`、`[2,3]`、`[2-4]`，并兼容中文逗号和顿号。
- 标记中的每个编号都能解析到唯一参考文献。
- 标记位于正文段落而不是公式、代码、任务书或参考文献区域。

转换示例：

```tex
评估方法\upcite{ref-2}。
多项研究\upcite{ref-3,ref-4,ref-5}。
```

参考文献输出进入带稳定 `\bibitem{ref-N}` 的环境，同时保留现有小四字号、1.5 倍行距和悬挂缩进。无法解析的引用不静默改写，Harness 输出稳定失败项。

### 4.2 公式说明段

正文模型中的段落保留原 `type`，新增 `role: equation_explanation`。分类条件为去除前导空白后以以下提示词开头：

- 式中
- 其中
- 这里
- 上式中

渲染规则：

- 使用 `\par\noindent`，取消首行缩进。
- 提示词和其后的第一个解释单元保持在同一行候选中，不插入空段或强制换行。
- 仅处理段首说明词，不改写正文中间出现的“式中”。
- 保留原始公式、标点和文字，不重写内容含义。

### 4.3 任务书动态横线

技术要求、工作内容和主要参考资料先按目标版心宽度排成视觉行，再逐行调用官方 `\ulinel{...}`。每个视觉行只有一条完整下划线，不再使用额外 `\hrule` 补齐。

规则：

- 技术要求、工作内容和主要参考资料正文固定为小四，不因内容增加而缩小。
- 中文按标点和字符边界换行；英文优先按空格、连字符和标点换行。
- 参考文献续行使用与编号宽度一致的悬挂缩进。
- 技术要求和工作内容保留模板最少行数；实际内容超过最少行数时追加 `\ulinel` 行。
- 任务书固定为连续两页。Harness 先根据“本科生毕业设计（论文）任务书”和“主要参考资料”定位这两页，不以聊天中的页码名称代替区域识别。
- 主要参考资料不固定为八行，按内容所需行数生成。新增横线后，同页后续字段整体下移；技术要求和工作内容也遵循相同规则。
- 每次改变行数后必须重新编译并测量两页的纵向边界，同时确认声明仍从任务书之后的下一页开始。只要所有内容仍在这两页内，就不是分页冲突。
- 固定字号下确实越过第二页页底时必须标记 `needs_review`，不得悄悄增加第三页或压缩字号。
- 禁止逐字符插入 `\allowbreak`。

### 4.4 书脊几何

书脊为单个窄矩形框和单个竖排内容轴：

1. 矩形框位于 A4 页面水平中心。
2. 框内题名、学生姓名、北京航空航天大学沿同一中轴自上而下排列。
3. 框线为连续细实线，四边完整，无重复边和断线。
4. 文本在框内水平居中，字符保持正立并逐字向下，不旋转整段。
5. 题名、姓名、学校之间使用固定的垂直间距；长题名不得挤压姓名或学校。
6. 页面无页眉、页脚和页码。

## 5. Harness 与失败项

新增或强化以下稳定检查：

- `citation_not_superscript_crossref`：正文仍有可解析的裸 `[n]`。
- `citation_target_missing`：引用键没有唯一 `\bibitem` 目标。
- `citation_key_duplicate`：两个参考文献条目生成了相同键；未被引用但合法存在的条目不因此失败。
- `equation_explanation_indented`：说明段未顶格。
- `equation_explanation_marker_orphan`：提示词单独成行。
- `taskbook_rule_join_visible`：任务书一行由多种横线机制拼接。
- `taskbook_font_size_reduced`：为塞入内容而小于小四。
- `taskbook_content_overflow`：新增行后内容越过任务书第二页页底，或声明不再从紧随其后的页面开始。
- `spine_frame_missing`：窄框缺失或不闭合。
- `spine_axis_misaligned`：题名、姓名、学校不在同一竖直中轴。
- `spine_not_page_centered`：书脊框未位于页面水平中心容差内。

失败项必须包含区域、证据、期望值和建议修复，不得因截图主观通过而忽略结构失败。

## 6. 测试与验证

按红绿循环逐项实施：

1. 单元测试证明裸引用会生成 `\upcite`，且每个键存在唯一 `\bibitem`。
2. 单元测试证明缺失引用目标时保留证据并失败，不生成虚假条目。
3. 单元测试证明公式说明段具有 `role`、`\noindent`，普通段落不受影响。
4. 单元测试证明任务书每个视觉行只使用一次 `\ulinel`，无 `\leaders\hrule` 和逐字符 `\allowbreak`。
5. 单元测试证明任务书内容增长只增加行数，不改变小四字号。
6. 单元测试证明书脊只有一个框和一个内容轴，并包含题名、姓名、学校。
7. 重跑 `C:\Users\admin\Desktop\删减毕设.docx`，编译最终 PDF。
8. 渲染并检查书脊页、语义定位得到的任务书连续两页、全部含引用页面和全部公式说明页面。
9. Harness 必须绑定最终 PDF SHA，逐页截图必须与该 PDF 像素一致。
10. 完整测试集通过，最终 `output/` 仍严格保持既定七项契约。

## 7. 验收标准

- 正文所有可解析数字引用均为右上角上标，点击或 LaTeX 引用关系指向正确参考文献条目。
- PDF 文本和生成 TeX 中不存在应转换却仍为裸文本的正文 `[n]`。
- “式中、其中、这里、上式中”说明段从左边界顶格，提示词不单独占行。
- 任务书技术要求和主要参考资料没有横线接缝，没有超出版心，没有缩小规定字号。
- 内容增多时横线行数随之增加，参考文献续行缩进一致；同页后续区块顺序下移但不得越过第二页页底，声明仍紧随任务书两页之后。
- 书脊具有闭合窄框，框位于页面水平中心，三段文本共用同一竖直中轴。
- 本轮不修改封面、摘要、目录、正文公式内容、图片内容或论文文字。

## 8. 非目标

- 不把原始参考文献内容自动改写为新的著录格式。
- 不猜测缺失参考文献或缺失引用编号。
- 不修改 BHOSC/BUAAthesis 上游类文件。
- 不通过缩小字体、压缩字符间距或 PDF 覆盖来隐藏溢出。
- 不顺带处理用户尚未提出的其他页面重排。
